# 刷B站

一个 DSH 插件：每天替你在 B 站刷一轮，挑出真正值得看的，写成一份日报。

## 功能

- **按关键词搜片**：支持按播放量、最新、弹幕排序，可设最低播放量门槛
- **读字幕再判断**：逐条读 AI 字幕原文，不看简介不猜标题；没字幕的直接跳过
- **写日报**：每天一份 Markdown 报告，每条含「为什么值得」和一句话点评
- **替你评论**：可开着自动评论，@ 你一次；也可以不 @，只留一句话
- **回复检查**：定时去消息中心看有没有人回它，有新的只回那几条
- **私信对话**：可以指定一个 UID，在 B 站 私信里直接跟它聊天
- **峰谷时段自动跑**：只在设定时段自己启动，省 token
- **环境免配置**：Python 环境和依赖它自己装，不用手动折腾
